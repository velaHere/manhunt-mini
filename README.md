# Manhunt Mini

A custom **Minecraft Manhunt minigame plugin** built for Minecraft servers, featuring Hunters vs Runners, player tracking, custom abilities, automated match progression, world-border mechanics, airdrops, spectator support, respawn handling, and multi-dimensional gameplay.

Manhunt Mini is designed as a more structured and action-focused take on traditional Minecraft Manhunt, with automated game management and additional mechanics that create shorter, more intense matches.

> Made with ❤️ by **Dhiren06**

---

## Features

- Hunters vs Runners gameplay
- Automated match start and game flow
- Runner head start
- Hunter tracking compass
- Hunter respawn timer after death
- Custom combat abilities
- Avatar/playstyle selection
- Airdrops with useful loot
- World border mechanics
- Village and Stronghold-based progression
- Overworld, Nether, and End support
- Spectator mode
- Custom scoreboard and team system
- Configurable gameplay settings
- Custom combat and gameplay mechanics

---

## Custom Abilities

Players can use different abilities such as:

- Dash
- Lunge
- Riposte
- Last Stand
- Blade Discipline

Different Avatars can provide different playstyles, including:

- Assassin
- Swordsman
- Default

---

## Hunter Tracking

Hunters receive a special compass that can:

- Track Runners
- Switch between Runner targets
- Update the target location during the match

This keeps the chase active even when players travel long distances.

---

## Airdrops

Airdrops appear during matches and provide useful resources.

They also create temporary hotspots where Hunters and Runners may end up fighting over the same loot.

---

## Game Flow

The plugin automatically manages the match from start to finish.

```text
Lobby
  ↓
Match Starting
  ↓
Runner Head Start
  ↓
Hunters Released
  ↓
Main Manhunt
  ↓
Village Stage
  ↓
Transition
  ↓
Stronghold Stage
  ↓
End Game
```

---

## Hunter Death System

Hunters do not instantly return after dying.

A respawn countdown temporarily removes them from the chase, making death more meaningful and giving Runners some breathing room.

---

## Multi-Dimensional Gameplay

The game supports:

- Overworld
- Nether
- End

Tracking and gameplay mechanics continue while players travel between dimensions.
